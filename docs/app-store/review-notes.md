# App Review notes (paste into "Notes" in App Review Information)

Sign-in required: **No** (no account; leave demo credentials empty).

> Fini is a fully offline personal budget app. There is no account, server or bank connection; all data is stored on the device.
>
> How to try it in under a minute:
> 1. Launch → choose language and currency (ILS default) → tap "Continue". A 24-word recovery phrase is shown for encrypted backups; tap "I saved it".
> 2. Tab "Quick add": enter 120, pick "Groceries", tap Save. Add a credit-card purchase with 3 installments to see the payments scheduled on billing dates.
> 3. Tab "Forecast": shows the Runway balance range to next payday and the Pulse stress index (0–100), with an explanation. Ask the assistant e.g. "How much can I spend until payday?"
> 4. Tab "Budgets": set a monthly budget per category.
>
> Encryption: standard algorithms only, for the user's own data at rest (ITSAppUsesNonExemptEncryption = NO).
> The app is built with Python (BeeWare/Toga) using native UIKit widgets; all code ships inside the bundle — no code is downloaded or executed from the network.
> The app does not provide financial advice, loans, trading or banking services.
